# EvmForAgent
EvmForAgent是面向 Hermes 等 AI Agent 的自托管 EVM 钱包工具包，采用 Python 与 Web3.py 构建，提供 12 个可独立运行的功能模块。支持多钱包标签管理、多链 RPC 主备切换、原生币及 ERC-20 余额查询、转账与授权、合约读写、ERC-721/1155 操作、事件日志读取和消息签名。可从交易哈希提取 calldata，结合 ABI 或函数签名解析参数、导出并修改调用模板。统一的命令行与 JSON 接口便于 Agent 集成，附带 Skill 和使用说明。私钥仅在本地加载与签名，RPC 独立保存在 CSV 中；写操作默认预览和模拟，显式执行后才广播，并支持 Nonce 协调、交易状态追踪、同笔重播及简单批量执行。
